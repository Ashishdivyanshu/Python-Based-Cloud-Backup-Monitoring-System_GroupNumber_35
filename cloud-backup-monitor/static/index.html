Documentation / System details

About BackupGuard

A local simulation for observing backup health and basic security signals.

What this system checks

Cloud backups are useful only when they remain available, current, and unchanged. BackupGuard checks a simulated cloud bucket and identifies common backup problems.

  • Availability — checks whether each expected backup exists.
  • Freshness — checks whether files were updated within the maximum age of 24 hours.
  • Integrity — compares SHA-256 hashes with a trusted baseline.
  • Audit and logging — records file operations and monitoring events.
Pipeline
Backup storage→Python monitoring→Detect problem→Log / alert

Scope and limitations

This project focuses on monitoring and basic security in a simulated environment. It does not connect to a live cloud provider.

  • Cloud storage is represented by a local folder.
  • User names are recorded but are not authenticated.
  • Local logs and baselines are not tamper-proof.
  • Modification time alone does not prove that a backup succeeded.
